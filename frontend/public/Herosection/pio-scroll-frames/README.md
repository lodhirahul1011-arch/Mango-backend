# PIO scroll sequence

Extract this ZIP. Give CODEX_PROMPT.md and the asset directories to Codex along with your existing website project. These assets are extracted from the supplied video; no new frames were generated.

Desktop: 193 WebP frames, 1440 x 616. Mobile: 97 WebP frames, 768 x 328. Both include the first and last source frames. Filenames start at frame-0000.webp. The manifest contains exact byte totals.

The clip shows two centered PIO packs, mango/lychee splashes, fruit and ice, with an initial reveal followed by subtle movement. This is a wide composition: preserve both packs with contain on narrow screens. Any existing video artifacts and corner mark are retained. Audio is omitted.

A sequence is not automatically smaller or faster than video. Only load one responsive variant, show the poster immediately, progressively fetch nearby frames and bound decoded-image memory. Desktop sequence is about 15.05 MiB; mobile about 3.18 MiB. Actual website speed and scroll smoothness need browser/network testing after integration.

The ZIP is a handoff asset kit, not a deployed website. FRAME_PREVIEW.jpg shows nine sample frames.
